# Play Console content rating — SportSphere

Use these answers on the IARC questionnaire. They match the finished app.

**Category:** Sports / Health & Fitness  
**Target age:** 13+ (Google account required). Expected rating: **Everyone / PEGI 3**.

## Questionnaire

| Question | Answer |
| --- | --- |
| Violence | No |
| Sexual content or nudity | No |
| Language | No (user-typed notes are not moderated chat; keep “user-generated content” below) |
| Controlled substances (alcohol, tobacco, drugs) | No |
| Gambling | No |
| User interaction | Users share club fixtures for a sport they follow. There is no private chat or social graph. |
| User-generated content | Yes — fixture titles/details and optional performance notes. No in-app reporting tool. Users can delete their own fixtures and account. |
| Location sharing | No |
| Digital purchases / ads | No |
| Unrestricted internet | The app loads HTTPS API data and Learn images. It does not embed an open web browser. |
| Age restriction | Users must have a Google / Firebase account. |

## Store listing age note

Do not tick “Designed for children” or Families. This is a campus sports-club app.
